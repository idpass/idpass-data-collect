# @idpass/publicschema

A narrow vendored mirror of [PublicSchema](https://publicschema.org) v0.2.0 and a Form.io generator that produces ID PASS DataCollect entity forms from PublicSchema concepts.

## Scope (v0.1.0)

- Concepts: Person, Group, Identifier
- Vocabularies: gender-type, identifier-type, country, language, relationship-type, group-type

## Usage

```ts
import { generateForm } from "@idpass/publicschema";

const personForm = generateForm("Person");
// → { id, name, title, entityType, formio, metadata: { publicSchemaVersion, concept, generatedAt } }
```

The vendored snapshot is regenerated by hand when a new upstream PublicSchema version is adopted. No automatic upstream fetch.

`entityForms[].generatedFrom = { source: "publicschema", ...metadata }`.
