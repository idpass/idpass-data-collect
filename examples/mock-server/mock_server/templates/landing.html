Conventions

  • system_id — stable UUID auto-assigned on create. Visible to the API, hidden here.
  • If-Match — pass updated_at to PATCH endpoints for optimistic concurrency.
  • updated_since — RFC 3339 timestamp for delta pulls.
  • Identifier ≠ Document — identifiers are coded values; documents carry them.
